# Library Management System

A lightweight web-based Library Management System built with Python and Flask to manage book inventory, member records, and borrowing workflows.

## Features

- **Book Inventory Management:** Add, view, update, and remove books in the library catalog.
- **Member & Borrowing Tracking:** Record book checkouts, returns, and real-time availability status.
- **Web Interface:** Clean browser-based UI powered by HTML templates.

## Tech Stack

- **Backend:** Python (Flask)
- **Frontend:** HTML / CSS (`templates/`)
